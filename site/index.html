설치하거나 가입해야 하나요?

아니요. Windows용 ZIP을 내려받아 압축을 풀고 PixelPin.exe를 실행하면 됩니다. 배포본에 .NET 런타임이 포함되어 있어 따로 설치하지 않아도 됩니다.

처음 실행할 때 Windows 보호 경고가 나와요.

현재 공개 배포본에는 코드 서명이 없습니다. Windows의 평판 기반 보호에 따라 처음 다운로드한 앱에 실행 경고가 표시될 수 있습니다. 공식 GitHub 릴리스의 출처와 SHA-256 확인 파일을 확인해 주세요. Microsoft의 실행 보호 안내

HDR 화면에서도 같은 색이 나오나요?

지원되는 환경에서는 고정밀 scRGB 캡처와 Windows SDR 밝기 보정을 사용합니다. 출력은 sRGB 기준이며 HDR의 밝기·색역을 완전히 재현하는 값은 아닙니다. DirectX 캡처를 사용할 수 없으면 호환 캡처로 표시됩니다.

CMYK 값으로 바로 인쇄해도 되나요?

CMYK는 화면 RGB에서 환산한 참고값입니다. ICC 인쇄 프로파일이 적용되지 않으므로, 실제 인쇄용 색상은 사용하는 출력 환경과 프로파일에서 확인해 주세요. HSV와 CMYK 표기는 일반 CSS 색상 문법이 아닙니다.

설정과 색상 기록은 어디에 저장되나요?

이 PC의 %LOCALAPPDATA%\PixelPin 폴더에 저장됩니다. 화면 이미지나 색상 기록을 서버로 전송하지 않습니다. 이 소개 사이트에도 분석 추적 코드를 넣지 않았습니다.
