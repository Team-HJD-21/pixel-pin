## Say hello to Pixel Pin

A small Windows utility for finding a screen color, pinning a pixel, and copying its HEX code.

### What’s included

- Live HEX and RGB values for the pixel under your pointer.
- Click once to pin a color; click again to resume.
- A magnified view of the surrounding 17 × 17 pixels.
- A copy button that shows the current color and adjusts its text for contrast.
- Eight recent colors, ready to copy again.
- An always-on-top window.
- Custom app, pause, and play icons.

### Download and run

Extract `Pixel-Pin-v1.0.0-win-x64.zip` and run `PixelPin.exe`.

- Windows 10 / 11, x64.
- .NET runtime included.
- No installer or account needed.
- A ZIP checksum is available in `SHA256SUMS.txt`.

### Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + Shift + C` | Copy the HEX code |
| `Ctrl + Shift + Space` | Pin / resume picking |

Screen clicks also reach the application underneath. Use the shortcut if you want to pin a color without clicking. HDR, display color processing, and protected content can affect sampling.

Color history from the earlier Digital Color Meter version is preserved.
