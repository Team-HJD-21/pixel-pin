## Make Pixel Pin your own

Open Settings in the top-right corner to choose your appearance, language, and color format. Changes apply immediately and stay with you next time.

### New in this release

- Light, dark, or follow device settings, with support for system theme changes.
- Korean, English, and Simplified Chinese throughout the app, including buttons and help text.
- Five output formats: HEX, RGB, HSL, HSV, and reference CMYK. Your selection is used for both display and copying.
- Recent colors can be copied in your currently selected format.
- Korean, English, and Simplified Chinese README pages.
- An official website with version-by-version release notes.

### Capture improvements

- DirectX desktop duplication is now the preferred capture path, with an additional path for older drivers.
- FP16 scRGB frames are normalized using the Windows SDR white level before conversion to sRGB.
- The app labels this path as `HDR/scRGB → sRGB`. If DirectX is unavailable, it explicitly labels compatibility capture instead.
- Clicking settings controls and dropdowns no longer toggles color pinning.

**HDR:** Standard HEX/RGB cannot represent the full brightness and gamut of HDR. A visual match still needs checking on the actual display and driver. HDR colors may differ in compatibility capture.

**CMYK:** These are reference values converted from screen RGB without an ICC print profile. They can differ from production print values. HSV and CMYK notation are not standard CSS syntax.

### Checks completed

- Display and settings synchronization across 45 combinations of three languages, three appearance options, and five formats.
- Reference color conversions, decimal formatting, and the HDR white-level normalization formula.
- Saving and restoring settings, pin/resume states, and actual DirectX screen capture.
- Standalone startup of the executable extracted from the release ZIP.
- Website routes, download links, sample color conversions, and clipboard success/failure handling.

### Download

Extract `Pixel-Pin-v1.1.0-win-x64.zip` and run `PixelPin.exe`.

- Windows 10 / 11, x64.
- .NET runtime included; no separate installation needed.
- Existing color history is preserved.
- Use `SHA256SUMS-v1.1.0.txt` to verify the ZIP.
