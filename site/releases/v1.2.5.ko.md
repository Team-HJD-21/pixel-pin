# macOS 업데이트 후 권한 유지 개선

업데이트할 때마다 화면 기록 권한을 지웠다가 다시 허용해야 했던 불편을 줄였습니다. 정식 배포에 고정된 자체 서명을 적용해 이후 버전에서도 같은 앱 신원을 사용합니다. 두 버전 사이의 업데이트 후 권한 유지는 실제 Mac에서 확인했습니다.

- 기존 화면 측정, 색상 포맷, 확대경과 설정 기능은 그대로 사용할 수 있습니다.
- 응용 프로그램 폴더에 설치한 앱은 기존처럼 자동 업데이트와 업데이트 확인을 지원합니다.
- 배포 과정에서 고정 서명을 검증하며, 서명키가 없으면 정식 릴리즈를 중단합니다.

기존 임시 서명 버전이나 별도 시험판에서 이번 정식판으로 처음 바꿀 때는 서명이 달라 화면 기록 권한을 한 번 다시 등록해야 할 수 있습니다. 시험판 사용자는 사이트의 정식 DMG로 교체하면 정식 업데이트 경로로 돌아옵니다.

자체 서명은 Apple Developer ID 서명이나 공증이 아니므로 첫 실행 보안 경고가 없어지지는 않습니다. macOS 자체의 화면 접근 재확인도 표시될 수 있습니다. Windows 버전에는 변경이 없습니다.
