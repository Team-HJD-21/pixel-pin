# 改善 macOS 更新后的权限保留

不必再为每次更新反复移除并重新授予屏幕录制权限。macOS 正式版现已使用固定的自签名证书，让后续版本保持相同的应用身份。我们已在实际 Mac 上确认，两版之间更新后权限仍可正常使用。

- 实时取色、颜色格式、放大镜和设置的使用方式保持不变。
- 将 Pixel Pin 安装到「应用程序」文件夹后，即可使用自动更新和「检查更新」。
- 发布流程会验证固定签名；缺少签名密钥时会停止发布正式版。

从旧版临时签名应用或独立测试版首次换到本正式版时，应用签名会发生一次变化，因此可能需要重新登记一次屏幕录制权限。如果你安装过测试版，请从网站下载正式版 DMG 并替换应用，以恢复正式更新渠道。

自签名并不等同于 Apple Developer ID 签名或公证，因此首次打开时仍可能出现安全提示。macOS 自身也可能再次确认屏幕访问权限。本次更新不涉及 Windows 版本。
