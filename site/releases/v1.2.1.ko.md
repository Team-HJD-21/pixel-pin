# macOS 정식 출시

Pixel Pin을 이제 Apple silicon과 Intel Mac에서도 사용할 수 있습니다. macOS 13 이상을 지원합니다.

- DMG를 열고 앱을 응용 프로그램 폴더로 드래그하세요. 설치 화면에 한국어·영어·중국어 안내를 담았습니다.
- 권한을 허용하면 커서가 있는 화면의 색을 자동으로 측정합니다. 화면 선택 방식도 설정에서 사용할 수 있습니다.
- HEX, RGB, HSL, HSV, CMYK 참고값과 픽셀 확대경을 지원합니다.
- 라이트·다크·기기 설정, 세 가지 언어, 최근 색상 기록을 제공합니다.
- `⌘ + ,`로 설정을 열고, 바깥을 누르거나 Esc로 닫으세요. 닫기 버튼은 기본적으로 Dock으로 최소화하며 설정에서 완전 종료로 바꿀 수 있습니다.
- 응용 프로그램 폴더에 설치하면 Sparkle 업데이트와 수동 업데이트 확인을 사용할 수 있습니다.

현재 배포본은 Apple Developer ID 서명·공증을 받지 않았습니다. macOS 보안 경고나 화면 기록 권한 재승인이 필요할 수 있습니다. Sparkle의 업데이트 서명은 Apple 공증과 별개입니다.

화면 출력은 sRGB 기준이며 HDR의 전체 밝기와 색역을 보존하지 않습니다. CMYK는 인쇄 프로파일 없는 참고값입니다.
