# macOS 자동 업데이트 확인용 릴리즈

정식 v1.2.5에서 다음 버전으로 업데이트하는 흐름을 확인할 수 있도록 v1.2.6을 배포했습니다. 앱 기능은 그대로 두고 버전과 업데이트 정보를 갱신했습니다.

- v1.2.5와 같은 고정 서명키와 정식 업데이트 경로를 사용합니다.
- 응용 프로그램 폴더에 설치한 v1.2.5에서 **업데이트 확인**을 눌러 설치할 수 있습니다.
- 업데이트 후 화면 기록 권한을 변경하지 않은 상태에서 색 측정이 되는지, 앱을 다시 켜도 정상인지 확인해주세요.

사이트의 macOS 다운로드도 v1.2.6으로 갱신했습니다. Windows 버전에는 변경이 없습니다.
