# Pixel Pin 正式登陆 Mac

Pixel Pin 现已支持搭载 Apple 芯片或 Intel 处理器的 Mac，需要 macOS 13 或更高版本。

- 打开 DMG，将 Pixel Pin 拖入“应用程序”文件夹即可安装。安装窗口提供韩语、英语和简体中文说明。
- 授予权限后，应用会跟随光标在不同显示器上取色。也可以在设置中切换为系统屏幕选择器。
- 支持复制 HEX、RGB、HSL、HSV 和 CMYK 参考值，并提供像素放大镜，方便精确选择。
- 提供浅色、深色和跟随系统三种外观，支持三种语言，并保留最近使用的颜色。
- 按 `⌘ + ,` 打开设置，点击窗口外或按 Esc 即可关闭。关闭按钮默认将窗口最小化到程序坞，也可在设置中改为退出应用。
- 将应用安装在“应用程序”文件夹后，即可使用 Sparkle 更新及手动检查更新功能。

当前发行版未经 Apple Developer ID 签名和公证。macOS 可能会显示安全提示，或要求重新授予屏幕录制权限。Sparkle 更新签名用于验证更新包，与 Apple 公证是两回事。

取色结果以 sRGB 为基准，无法保留 HDR 的完整亮度和色域。CMYK 数值仅供参考，未应用印刷配置文件。
