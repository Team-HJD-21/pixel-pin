## 让 Pixel Pin 更合你的心意

点击右上角的设置图标，即可选择外观、语言和颜色格式。更改会立即生效，下次打开时也会保留。

### 新增功能

- 支持浅色、深色和跟随系统，并会响应系统主题的变化。
- 应用提供韩语、英语和简体中文，按钮、设置和提示均已翻译。
- 支持 HEX、RGB、HSL、HSV 和 CMYK 参考值。显示与复制使用同一套格式设置。
- 最近颜色也可按当前选择的格式重新复制。
- GitHub README 可切换韩语、英语和简体中文。
- 新增官方网站和按版本整理的更新日志。

### 采集改进

- 优先使用 DirectX 桌面复制，并为较旧的驱动提供额外采集路径。
- 对 FP16 scRGB 画面，先按 Windows SDR 白电平进行归一化，再换算为 sRGB。
- 该路径会显示为 `HDR/scRGB → sRGB`。DirectX 不可用时，会明确显示兼容采集模式。
- 点击设置控件或下拉选项时，不再切换颜色的固定状态。

**关于 HDR：** 普通 HEX/RGB 无法完整表达 HDR 的亮度和色域。与屏幕实际观感的一致性，仍需结合具体显示器和驱动验证。兼容采集下的 HDR 颜色可能存在偏差。

**关于 CMYK：** 此数值由屏幕 RGB 换算，仅供参考，未应用 ICC 印刷配置文件，可能与正式印刷数值不同。HSV 和 CMYK 的这种写法并非标准 CSS 语法。

### 下载

解压 `Pixel-Pin-v1.1.0-win-x64.zip`，然后运行 `PixelPin.exe`。

- 面向 Windows 10 / 11，x64。
- 已包含 .NET 运行时，无需另行安装。
- 保留已有的颜色记录。
- 可使用 `SHA256SUMS-v1.1.0.txt` 校验 ZIP 文件。
