# A consistent identity for macOS updates

Updating Pixel Pin should no longer mean removing and granting Screen Recording permission again every time. Mac releases now share a fixed self-signing certificate, so future updates keep the same app identity. Permission was retained during an update test on a real Mac.

- Your color formats, magnifier, live sampling and settings work as before.
- Install Pixel Pin in Applications to use automatic updates or Check for Updates.
- Release checks verify the fixed signature and stop publication if its signing key is missing.

The first move from an older ad-hoc build or the separate test app changes the signing identity. You may need to register Screen Recording permission once for this transition. If you used the test app, replace it with the official DMG from the website to return to regular updates.

Self-signing is separate from Apple's Developer ID and notarization, so first-open security warnings may still appear. macOS can also request renewed screen access independently. The Windows version is unchanged.
