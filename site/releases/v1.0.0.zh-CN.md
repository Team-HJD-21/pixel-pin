## Pixel Pin，首次亮相

一款小巧的 Windows 工具：找到屏幕上的颜色，固定像素，再复制 HEX 代码。

### 首发功能

- 实时显示光标所在像素的 HEX 和 RGB 数值。
- 点击一次固定颜色，再次点击继续取色。
- 放大显示周围 17 × 17 像素。
- 复制按钮使用当前颜色作为背景，并自动调整文字对比度。
- 保存最近复制的八个颜色，点击即可再次复制。
- 窗口始终置顶。
- 专门绘制的应用、暂停和播放图标。

### 下载并运行

解压 `Pixel-Pin-v1.0.0-win-x64.zip`，然后运行 `PixelPin.exe`。

- 面向 Windows 10 / 11，x64。
- 已包含 .NET 运行时。
- 无需安装程序或账号。
- `SHA256SUMS.txt` 中提供 ZIP 校验值。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Shift + C` | 复制 HEX 代码 |
| `Ctrl + Shift + Space` | 固定颜色或继续取色 |

屏幕点击也会传递给下方的程序。如果只想固定颜色而不触发点击，请使用快捷键。HDR、显示颜色处理和受保护内容可能影响取色结果。

旧版 Digital Color Meter 的颜色记录会保留。
