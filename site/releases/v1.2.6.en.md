# Try the next macOS update

Version 1.2.6 lets you test updating from the official v1.2.5 release. App features stay the same; only the version and update information have changed.

- Uses the same fixed signing key and regular update channel as v1.2.5.
- In v1.2.5, installed in Applications, choose **Check for Updates** to install this release.
- Without changing Screen Recording permission, check that color sampling works after the update and again after quitting and reopening the app.

The website's macOS download now offers v1.2.6. The Windows version is unchanged.
